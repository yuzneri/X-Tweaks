# X Tweaks

[English](README.md)

X Pro（pro.x.com、旧 TweetDeck）と x.com のタイムラインから不要な投稿を隠し、外観を変更するブラウザ拡張です。

設定は次の5つの範囲に置けます。
狭い範囲の指定が優先され、広い範囲で指定した色や大きさは狭い範囲で「X のまま」に戻せます。

- グローバル
- アカウント
- サイト（X Pro / x.com）
- サイトごとのアカウント
- いま見ているカラム（X Pro）またはビュー（x.com）

## インストール

- [Firefox アドオン](https://addons.mozilla.org/ja/firefox/addon/x-tweaks/)
- [Chrome 拡張機能](https://chromewebstore.google.com/detail/knbinffoidihjchpoahlnfpippkllcia)

## フィルタ

条件に一致した投稿をどう扱うかを、ルールとして並べます。
上から見て最初に一致したルールが効きます。
ルールごとに、消さずに有効と無効を切り替えられます。

条件に使えるもの:

- **文字列**：本文、引用元の本文、ユーザーID、表示名、リポストした人のID、引用元の投稿者のIDと表示名、返信先のID、アンケートの選択肢、リンク先のドメイン、カードの見出し、スペースの名前、記事の見出しと書き出し、投稿の言語（Xが判定した`ja`・`en`などのコード）、画像の説明
- **一致方法**：含む、完全に一致、正規表現、自分自身
- **投稿の種類**：リポスト、引用、リプライ、コミュニティノート付き、コミュニティノートの評価待ち、アンケート（受付中・結果）、リンクカード付き、スペース付き、記事付き、広告・プロモ、画像・動画あり、認証済みアカウント、本文にリンクあり、説明のない画像・動画
- **投稿の古さ**：「1時間より古い」のような指定（単位は分、時間、日）。投稿を読んだ時点で判定するので、古いほうだけを指定できます
- **数**：リプライ、リポスト、いいね、表示の件数と、本文の文字数・ハッシュタグの数・メンションの数を「100以上」「5以下」のように指定します。Xが数字を出していない件数は、条件に当たりません
- **条件の反転**：文字列と投稿の種類は裏返せます。古さと件数に反転はありません（片方は向きが1つ、もう片方は「以上・以下」で両側を言えるため）

一致したときの動作:

- **折りたたむ**：投稿を1行にまとめます（「表示」を押すと戻ります）
- **非表示**：投稿ごと消します
- **ハイライト**：投稿の背景に色を付けます
- **強調**：一致した文字だけに色を付けます
- **何もしない**：その投稿への指定を、上位の範囲のものまで含めて止めます

## 外観

X Pro ではカラムごとに、x.com ではビューごと（ホーム、通知、ブックマーク、リスト、人のプロフィール、検索）に変えられます。
同じ項目は、より広い範囲にも置けます。

- **カラムの幅**（X Pro のみ）
- **ポストを詰める**：余白を詰め、アバターを小さくし、ボタンの行を畳みます
- **本文の字の大きさ**
- **本文の行数の上限**：超えた投稿は「さらに表示」で開けます
- **説明や引用を出す文字数**：画像の説明、引用ポスト、カードの見出しを画面に出す長さです（既定は80字）
- **本文の改行**：書かれた改行を空白1つに畳みます
- **リプライ・リポスト・いいね・表示の件数**：Xが丸めた件数（「22万」）を、そのままの数字（「221,250」）で出します。Xが正確に出している件数はそのままです
- **画像と動画の表示**：そのまま／そのまま（説明つき）／説明のテキスト／マーク（📷 🎬）／表示しない
- **サムネイルの高さの上限**
- **リンクカードと記事の表示**：そのまま／テキスト（🔗 📄）／マーク／表示しない
- **引用ポストの表示**：同じ4通り（テキストにすると「💬 引用の本文（表示名 @ID）」の1行）
- **時刻の表示**：そのまま／日付と時刻／両方
- **配色**：カラム名の帯、タイムラインの背景、タイムラインの外側（x.com のみ）、投稿フォームの背景、カラム名、投稿者の名前、本文、薄い文字、リンク、投稿の境目の線
- **ハイライトの色を重ねる先**：タイムラインの背景か、X の背景
- **ハイライトで文字が読めなくなったとき**：文字の色を自動で直すかどうか

未指定の項目は、そのサイトの表示のままです。
投稿を開いて読んでいる場所では、詰め方、行数の上限、改行の畳み、カードや画像を隠す指定は効きません。

投稿フォームの背景色は、そこから投稿するアカウントとサイトで決まります。
アカウントごとに色を変えておけば、いま書いている投稿がどのアカウントのものか一目で分かります。

### 画像の説明

- 設定に関わらず、カーソルを合わせると説明が出ます（X Pro はこれをどこにも表示しないためです）
- カーソルの無いタッチ端末では、「そのまま（説明つき）」を選ぶと画像の下に文字で出ます
- 1つの投稿に複数の画像があるときは、「2枚目：」のようにどの画像のものかが付きます
- 引用ポストの画像には、どの表示のときも触れません
- 説明の無い画像に X が入れる汎用の文言（「画像」など）は、説明として扱いません。見たページから自動で調べ、「その他 → 設定」で直せます

## X が差し込むもの

X がタイムラインに差し込む、ポストではない塊を消せます。
サイトごとに1つの設定です。

- **おすすめユーザー**：見出しから「さらに表示」まで丸ごと消します。x.com では横の欄に出るものも一緒に消えます
- **ポストの下の「もっと見つける」**：会話そのものは残ります

## 投稿

新規ポストの投稿フォームについて切り替えられます（X Pro 全体で1つの設定です）。
同じタグを付けて何本も続けて投稿するときのための機能で、どちらも既定は切です。

- **投稿フォームを開き直す**：投稿後に閉じたフォームを、すぐに開き直します
- **ハッシュタグを残す**：書いたタグを次の投稿フォームに入れ、カーソルはその手前に置きます

返信と引用には効きません。

## 詳細検索

X の検索を、演算子を覚えていなくても組み立てられる欄として出します（**x.com のみ**）。
既定では出しません。

置き場は右の欄で、開いているページによって変わります。

- **タイムライン**：X の検索窓の下（窓はそのまま残ります）
- **検索結果**：X 自身の検索フィルターと入れ替わります
- **話題を検索**：欄の先頭

いつも見えているのは、開くタブ（話題のポスト、最新、アカウント、メディア、リスト。最初は「最新」）と、次の5つの欄です。

- すべてのキーワードを含む（ここに書いた演算子は、そのまま X に渡ります）
- キーワード全体を含む
- いずれかのキーワードを含む
- キーワードを含まない
- ハッシュタグを含む

残りは畳まれた群に入っています。

- **アカウント**：このアカウントの投稿／への返信／に言及（それぞれ「除く」に切り替えられます）
- **期間**：日付と時刻。時刻を空にすると、その日を丸ごと扱います
- **フィルター**：リンク、画像、動画、認証済みアカウントの有無、返信かどうか、言語、フォローしているアカウントだけ、近くの場所だけ
- **反応の数**：返信数、いいね数、リポスト数の下限

### 結果から除く

X の検索では指定できないものを、表示された結果に対して行います。
「フィルター」の中にあり、効くのは検索結果のページだけです。
保存はしませんが、タブを開いているあいだは引き継ぎます。

- リポスト
- 表示名のみに引っかかった投稿
- ユーザーIDのみに引っかかった投稿
- ハッシュタグ・リプライ・リポスト・いいね・表示が、指定した数**以上**の投稿

名前の2つは検索語が分かるときだけ効き、クエリが名指ししたアカウントは除きません。
数のほうは上限の指定です。X の検索が言えるのは下限（「反応の数」の欄）だけなので、
両方を使うと「100以上300未満」のような幅で絞れます。表示数は X の検索が扱わないので、ここだけで指定できます。
ハッシュタグは X 自身がタグとして扱ったものを数えるので、`C#` のようなものは数に入りません。

### フォームと X の検索窓

- 検索結果を開くと、アドレスの内容がフォームに入ります。トレンドやハッシュタグから来た検索も、打ち直さずに絞り込めます
- X の窓に打った内容も、どのページでもフォームに入ります
- 値の入った群は、畳まれずに開いた状態で出ます
- フォームの内容が X の窓に映るのは、検索結果のページだけです

この拡張が出さない演算子も失われず、届いたまま X に渡ります。

## タイムラインの周り

x.com がタイムラインの周りに描くものを消せます（x.com 全体で1つの設定です）。
設定画面のチェックは**「表示する」**の意味で、最初はすべて入っています。

- **横の欄を消してタイムラインを広げる**：検索窓も含めて横の欄をまるごと消し、1050px までタイムラインを広げます
- **横の欄の中身**：プレミアムの勧誘、本日のニュース、速報とトレンド、関連性の高いユーザー、利用規約などのリンク
- **左に並ぶ項目**：話題を検索、フォローする、チャット、Grok、履歴（ブックマーク・いいね）、クリエイタースタジオ、記事、プレミアム、プロフィール、ポストボタン
- **「もっと見る」の中の項目**：リスト、コミュニティ、コミュニティノート、ビジネス、広告、スペースを作成、ミュートするキーワードを追加、設定とプライバシー
- **タイムライン上の投稿フォーム**：先頭にあるものです（返信を書くボックスは残ります）
- **右下の項目**：Grok とチャット
- **新着を自動で読み込む**：X が出す新着のボタンを、先頭にいるあいだ自動で押します

横の欄をまるごと消すと、詳細検索フォームも一緒に消えます。

## 設定画面の開き方

主な編集はサイトの中で行います。

| サイト | 入口 | 開く場所 |
| --- | --- | --- |
| X Pro | カラムの列オプション（ヘッダーの「…」） | そのカラムの設定 |
| X Pro | 左下のメニュー | グローバルの設定 |
| x.com | サイドナビの「もっと見る」 | いま見ているビューの設定 |

サイト全体の設定（「X が差し込むもの」と、x.com では「タイムラインの周り」）は、そのサイトの一覧の先頭にあります。
