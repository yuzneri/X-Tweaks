# X Pro Tweaks

[English](README.md)

X Pro（pro.x.com、旧 TweetDeck）のタイムラインから不要な投稿を隠し、外観を変更するブラウザ拡張です。
設定はグローバル、アカウント、カラムの3つの範囲に置けます。

## インストール

- [Firefox アドオン](https://addons.mozilla.org/ja/firefox/addon/x-tweaks/)
- [Chrome 拡張機能](https://chromewebstore.google.com/detail/knbinffoidihjchpoahlnfpippkllcia)

## フィルタ

条件に使えるものは次のとおりです。

- **文字列**：本文、引用元の本文、ユーザーID、表示名、リポストした人のID、引用元の投稿者のID、引用元の投稿者の表示名、返信先のID、アンケートの選択肢、リンク先のドメイン、カードの見出し、スペースの名前、記事の見出しと書き出し
- **一致方法**：「含む」「完全に一致」「正規表現」「自分自身」
- **投稿の種類**：リポスト、引用、リプライ、コミュニティノート付き、コミュニティノートの評価待ち、アンケート（回答受付中）、アンケート（結果）、リンクカード付き、スペース付き、記事付き、広告・プロモ、画像・動画あり
- **投稿の古さ**：「1時間より古い」「30分より新しい」のような指定（単位は分、時間、日）
- **条件の反転**：どの条件も裏返せます

一致したときの動作は次から選びます。

- **折りたたむ**：投稿を1行にまとめます。「表示」を押すと元に戻ります
- **非表示**：投稿ごと消します
- **ハイライト**：投稿の背景に色を付けます
- **強調**：一致した文字だけに色を付けます
- **何もしない**：その投稿への指定を、上位の範囲のものまで含めて止めます

ルールは範囲の中で並べ替えられ、上から見て最初に一致したルールの動作が効きます。
ルールごとに、消さずに有効と無効を切り替えられます。

## 外観

カラムごとに次の項目を変えられます。

- **カラムの幅**
- **ポストを詰める**：ポストの上下の余白を詰め、アバターを小さくし、ボタンの行を畳みます。リポストといいねは名前の横（「…」の左）に移り、返信・表示回数などは隠れます。「さらに表示」も出しません（X 自身が出すものも含めて。続きは投稿を開くと読めます）
- **本文の字の大きさ**
- **本文の行数の上限**：超えた投稿は「さらに表示」で開けます（ポストを詰めているときは出しません）
- **本文の改行**：書かれた改行を空白1つに畳んで、1件あたりの高さを抑えられます
- **画像と動画の表示**：「そのまま」「マーク」（タイムラインから隠し、あった場所を示すマーク 📷 🎬 を本文に入れます）「表示しない」（隠すだけで何も残しません）
- **サムネイルの高さの上限**
- **リンクカードと記事の表示**：「そのまま」「テキスト」（本文の末尾に「🔗 見出し（ドメイン）」「📄 記事の見出し」の1行として入れ、枠は消します。リンク先はそのまま開け、色は X のリンク色に合わせます）「マーク」（文字を省いてマーク 🔗 📄 だけにします）「表示しない」
- **引用ポストの表示**：同じ4通りです。文字にすると「💬 引用の本文（表示名 @ID）」の1行になります（本文は80字で切り、続きはカーソルを合わせると出ます）。X Pro の引用枠にはリンク先が書かれていないので、この行は押しても飛びません
- **時刻の表示**：「そのまま」「日付と時刻」「両方」
- **配色**：次の8か所に色を指定できます
  - カラム名の帯の背景
  - カラムの背景
  - カラム名
  - 投稿者の名前
  - 本文
  - 薄い文字（時刻・件数・返信先）
  - リンク
  - 投稿と投稿の境目の線
- **ハイライトの色を重ねる先**：「カラムの背景」か「X の背景（カラムの色を無視）」
- **ハイライトで文字が読めなくなったとき**：文字の色を自動で直すかどうか

未指定の項目は X Pro のままです。
文字やマークにした行は本文の末尾に入ります。本文の改行をそのままにしているときは次の行に、空白に畳んでいるときは本文の続きに入ります。
本文の行数の上限を決めているときはマークだけになり、上限に収まる投稿ではそのまま末尾に、収まらない投稿では上限で切られて消えないよう本文の先頭に置きます（別行にはしません）。本文の無い投稿では、枠があった場所に入ります。
投稿を開いているカラムでは、ポストの詰め方・本文の行数の上限・改行の畳み・カードや画像を隠す指定は効きません（開いた投稿は読むためのものなので）。

## 投稿

新規ポストの投稿フォームについて、次を切り替えられます（拡張全体で1つの設定で、カラムやアカウントごとには持ちません）。

- **投稿フォームを開き直す**：投稿すると X Pro はフォームを閉じます。すぐに開き直して、そのまま次を書ける状態にします
- **ハッシュタグを残す**：書いたタグを次の投稿フォームに入れ、カーソルはその手前に置きます。「開き直す」が入っていれば開き直したフォームに、入っていなければ次に自分で開いたときに入ります

同じタグを付けて何本も続けて投稿するときのための機能です。
どちらも既定は切で、切のままなら X Pro のとおりに動きます。

返信・引用には効きません。投稿に失敗したときも何もしません。

## 設定画面の開き方

主な編集は pro.x.com の中で行います。

| 入口 | 開く場所 |
| --- | --- |
| カラムの列オプション（ヘッダーの「…」） | そのカラムの設定 |
| X Pro の左下メニュー | グローバルの設定 |

## 開発

```
npm install
npm run build
```
