# X Tweaks

[English](README.md)

X Pro（pro.x.com、旧 TweetDeck）と x.com のタイムラインから不要な投稿を隠し、外観を変更するブラウザ拡張です。
設定はグローバル、アカウント、サイト（X Pro / x.com）、サイトごとのアカウント、いま見ているカラムまたはビューの5つの範囲に置けます。
狭い範囲の指定が優先され、広い範囲で指定した色や大きさは狭い範囲で「X のまま」に戻せます。

## インストール

- [Firefox アドオン](https://addons.mozilla.org/ja/firefox/addon/x-tweaks/)
- [Chrome 拡張機能](https://chromewebstore.google.com/detail/knbinffoidihjchpoahlnfpippkllcia)

## フィルタ

条件に使えるものは次のとおりです。

- **文字列**：本文、引用元の本文、ユーザーID、表示名、リポストした人のID、引用元の投稿者のID、引用元の投稿者の表示名、返信先のID、アンケートの選択肢、リンク先のドメイン、カードの見出し、スペースの名前、記事の見出しと書き出し
- **一致方法**：「含む」「完全に一致」「正規表現」「自分自身」
- **投稿の種類**：リポスト、引用、リプライ、コミュニティノート付き、コミュニティノートの評価待ち、アンケート（回答受付中）、アンケート（結果）、リンクカード付き、スペース付き、記事付き、広告・プロモ、画像・動画あり
- **投稿の古さ**：「1時間より古い」「30分より新しい」のような指定（単位は分、時間、日）
- **条件の反転**：どの条件も裏返せます

一致したときの動作は次から選びます。

- **折りたたむ**：投稿を1行にまとめます。「表示」を押すと元に戻ります
- **非表示**：投稿ごと消します
- **ハイライト**：投稿の背景に色を付けます
- **強調**：一致した文字だけに色を付けます
- **何もしない**：その投稿への指定を、上位の範囲のものまで含めて止めます

ルールは範囲の中で並べ替えられ、上から見て最初に一致したルールの動作が効きます。
ルールごとに、消さずに有効と無効を切り替えられます。

## 外観

X Pro ではカラムごとに、x.com ではビューごと（ホーム・通知・ブックマーク・リスト・人のプロフィール・検索）に、次の項目を変えられます。
同じ項目はグローバル・アカウント・サイト・サイトごとのアカウントの範囲にも置けます（狭いほうが優先されます）。

- **カラムの幅**（X Pro のみ）
- **ポストを詰める**：ポストの上下の余白を詰め、アバターを小さくし、ボタンの行を畳みます。リポストといいねは名前の横（「…」の左）に移り、返信・表示回数などは隠れます。「さらに表示」も出しません（X 自身が出すものも含めて。続きは投稿を開くと読めます）
- **本文の字の大きさ**
- **本文の行数の上限**：超えた投稿は「さらに表示」で開けます（ポストを詰めているときは出しません）
- **説明や引用を出す文字数**：画像の説明・引用ポスト・カードの見出しを画面に出す長さです。未指定なら80字。超えたぶんは「さらに表示」で開けます
- **本文の改行**：書かれた改行を空白1つに畳んで、1件あたりの高さを抑えられます
- **画像と動画の表示**：「そのまま」「そのまま（説明つき）」（画像はそのままに、投稿者が書いた説明を画像の下に添えます。続きは「さらに表示」で開けます）「説明のテキスト」（説明を「📷 説明」の1行として本文に入れ、画像は隠します。画像が複数あるときは画像ごとにマークを置き、その右にその画像の説明を入れます（例「📷 📷 2枚目の説明 📷 📷 4枚目の説明」）。説明の無い画像はマークだけになります）「マーク」（タイムラインから隠し、あった場所を示すマーク 📷 🎬 を本文に入れます）「表示しない」（隠すだけで何も残しません）
  マークは画像の枚数だけ並びます（4枚なら 📷📷📷📷）。隠しても何枚あったかは分かります。引用ポストの画像は数えません
- **サムネイルの高さの上限**
- **リンクカードと記事の表示**：「そのまま」「テキスト」（本文の末尾に「🔗 見出し（ドメイン）」「📄 記事の見出し」の1行として入れ、枠は消します。リンク先はそのまま開け、色は X のリンク色に合わせます）「マーク」（文字を省いてマーク 🔗 📄 だけにします）「表示しない」
- **引用ポストの表示**：同じ4通りです。文字にすると「💬 引用の本文（表示名 @ID）」の1行になります（本文は80字で切り、続きはカーソルを合わせると出ます）。X Pro の引用枠にはリンク先が書かれていないので、この行は押しても飛びません
- **時刻の表示**：「そのまま」「日付と時刻」「両方」
- **配色**：次の10か所に色を指定できます
  - カラム名の帯の背景（X Pro のみ）
  - タイムラインの背景 — X Pro ではカラムの中
  - タイムラインの外側（x.com のみ）— 左に並ぶ項目、横の欄、その外の余白。タイムライン自体は X のまま残るので、上の指定と別の色にできます
  - 投稿フォームの背景 — そこから投稿するアカウントとサイトで決まります。アカウントごとに色を変えておけば、いま書いている投稿がどのアカウントのものか一目で分かります。片方のサイトだけ別の色にしたり、出さないようにしたりもできます。X Pro の投稿ドロワー、x.com の投稿画面、x.com のタイムライン先頭のボックスに効きます
  - カラム名（X Pro のみ）
  - 投稿者の名前
  - 本文
  - 薄い文字（時刻・件数・返信先）
  - リンク
  - 投稿と投稿の境目の線
- **ハイライトの色を重ねる先**：「タイムラインの背景」（上で指定した色）か、「X の背景（その色を無視）」
- **ハイライトで文字が読めなくなったとき**：文字の色を自動で直すかどうか

設定画面では、カラムだけのもの（幅・カラム名まわり）が名前の付いた囲みに分かれています。
どの範囲を開いても項目の置き場は同じで、そこで効かないものは出ません（x.com にカラムは無く、X Pro にタイムラインの外側はありません）。

色と数値の欄には、広い範囲の指定を打ち消す「X のまま」が出ます（広い範囲で指定があるときだけ）。
たとえばアカウントに付けた投稿フォームの色を、x.com では出さない、といった指定ができます。

サイトのタブには「X Proのアカウント」「x.comのアカウント」の一覧があります。
アカウントの指定を片方のサイトだけ変えたい・出したくないときは、ここに書きます（「アカウント」の範囲はどちらのサイトにも効きます）。

画像に書かれた説明は、設定に関わらずカーソルを合わせると出ます（X Pro はこれをどこにも表示しないため）。「説明のテキスト」「マーク」では本文に入れた行に、「そのまま」では画像そのものに付きます。
カーソルの無いタッチ端末ではこの方法では読めないので、指だけで読みたいときは「そのまま（説明つき）」を選んでください。画像の下に説明が文字で出ます。
1つの投稿に複数の画像があるときは、まとめて1つに1行ずつ入り、「2枚目：」のようにどの画像の説明かが付きます（説明の無い画像は飛ばすので、番号は実際の並び順を指します）。
引用ポストの画像には、どの表示のときも触れません。説明を入れないのはもちろん、マークの数にも数えません。それは引用元の人が書いた言葉・引用元の投稿の中身であって、引用した側のポストに置くと引用した人のものとして読めてしまうためです。引用ポストそのものは、引用ポストの設定で扱います。
ポストを開いたときに X 自身が画像に「ALT」ボタンを出す場合は、そこには入れません（同じ内容が二重になるため）。ボタンの出ない画像には、開いた画面でも入ります。
説明の無い画像には X が汎用の文言を入れる（日本語表示なら「画像」、動画なら「埋め込み動画」）ので、それは説明として扱いません。この文言は X の表示言語のものなので、見たページから自動で調べます。調べた結果は「その他 → 設定」に出て、手で直せます（手で書いた行はそのまま残ります）。

未指定の項目は、そのサイトの表示のままです。
文字やマークにした行は本文の末尾に入ります。本文の改行をそのままにしているときは次の行に、空白に畳んでいるときは本文の続きに入ります。
画面に出すぶんは既定で80字（「説明や引用を出す文字数」で変えられます）。これはキャプションでも本文に入れる行でも同じです。長い説明や引用は続きが隠れます。そのときは**「さらに表示」が出て、押すと全文になります**。本文の行数の上限に引っかかっていなくても、行のほうに続きがあれば出ます。出し切っている行には出ません（マークにカーソルを合わせたときのツールチップも出ません。同じ内容を繰り返すだけのため）。
本文が省略されているポストでは、行はマークだけになり、本文の外（本文と「さらに表示」の間）に立ちます。「さらに表示」を押すと、本文と行の両方が開いて全文になります。
省略は拡張の行数の上限によるものだけでなく、X 自身が長い投稿を切っている場合も含みます。本文の無い投稿では、枠があった場所に入ります。
読むために開いた場所では、ポストの詰め方・本文の行数の上限・改行の畳み・カードや画像を隠す指定は効きません（X Pro なら投稿を開いているカラム、x.com ならポストのページ）。

## X が差し込むもの

X がタイムラインに差し込む、ポストではない塊を消せます。両サイトに効く設定で、カラムごと・ビューごとには持たず、サイト全体で1つです（どこに出すかを決めているのは X であって、読む側ではないためです）。

- **おすすめユーザー**：タイムラインに割り込む塊を、見出しから「さらに表示」まで丸ごと消します。x.com では横の欄に出るものも一緒に消えます
- **ポストの下の「もっと見つける」**：会話の返信が尽きたあとに X が並べるポストです。会話そのものは残ります

答えはサイトごとに別々に持ちます。片方だけ消す、ということができます。

「おすすめユーザー」は以前、外観のカラムごとの設定でした。ここへ移したため、以前の値は引き継がれません。消していた方は、もう一度入れ直してください。ほかの設定はそのままです。

## 投稿

新規ポストの投稿フォームについて、次を切り替えられます（X Pro に効く設定で、カラムごとには持たず X Pro 全体で1つです）。

- **投稿フォームを開き直す**：投稿すると X Pro はフォームを閉じます。すぐに開き直して、そのまま次を書ける状態にします
- **ハッシュタグを残す**：書いたタグを次の投稿フォームに入れ、カーソルはその手前に置きます。「開き直す」が入っていれば開き直したフォームに、入っていなければ次に自分で開いたときに入ります

同じタグを付けて何本も続けて投稿するときのための機能です。
どちらも既定は切で、切のままなら X Pro のとおりに動きます。

返信・引用には効きません。投稿に失敗したときも何もしません。

## タイムラインの周り

x.com がタイムラインの周りに描くページ自体を消せます（x.com に効く設定で、ビューごとには持たず x.com 全体で1つです。どのビューを見ていても同じものが同じ場所にあるためです）。

- **横の欄を消してタイムラインを広げる**：検索窓も含めて横の欄をまるごと消し、その分だけタイムラインを広げます。広がるのは2つが並んで収まっていた幅（1050px）までで、窓がどれだけ横長でもそこで止まります。1つのスイッチにしてあるのは、欄を出したまま広げると欄が窓の外へ押し出されるためです
- **横の欄の中身**（それぞれ個別に）：プレミアムの勧誘・本日のニュース・速報/トレンド・関連性の高いユーザー（人のプロフィールの横に出るもの）・利用規約などのリンク。検索窓は一覧にありません（ほかが何も無い欄は、欄が無いより価値が薄いためです。その場合は上の「まるごと消す」を使ってください）。欄ごと消しているときは効かなくなり、設定画面もそう見えます
- **左に並ぶ項目**（それぞれ個別に）：話題を検索・フォローする・チャット・Grok・履歴・クリエイタースタジオ・記事・プレミアム・プロフィール・ポストするボタン。X が出していない項目は、そもそも消すものがありません。行き先で見分けているので、Grok は SuperGrok を、プレミアムはプレミアムプラスを含みます。ホーム・通知・「もっと見る」は一覧にありません（「もっと見る」はこの設定を開く入口なので、隠せるようにしていません）
- **「もっと見る」の中の項目**（それぞれ個別に）：リスト・コミュニティ・コミュニティノート・ビジネス・広告・スペースを作成・ミュートするキーワードを追加・設定とプライバシー。メニューそのものは残り、この設定を開く項目も残ります
- **投稿ボックス**：タイムラインの先頭にあるものです。ポストのページで返信を書くボックスは X にとって同じ部品ですが、そちらは残ります
- **右下のバー**：Grok とチャットの2つを、それぞれ個別に消せます
- **新着を自動で読み込む**：X は新着を保留してタイムラインの上にボタンを出しますが、それが出たらすぐに押して自動で更新します。先頭にいるときだけです（押すと新着の位置へ移動するので、下のほうを読んでいる最中だと読んでいた場所から引き離されてしまいます）。下にいる間は押さずに待ち、先頭に戻ったときに取り込みます

設定画面のチェックは**「表示する」**の意味です。最初はすべて入っていて、外したものが消えます（「タイムラインを広げる」と「新着を自動で読み込む」だけは、チェック＝する、です）。

## 設定画面の開き方

主な編集はサイトの中で行います。

| サイト | 入口 | 開く場所 |
| --- | --- | --- |
| X Pro | カラムの列オプション（ヘッダーの「…」） | そのカラムの設定 |
| X Pro | 左下のメニュー | グローバルの設定 |
| x.com | サイドナビの「もっと見る」 | いま見ているビューの設定 |

どの入口から開いても、サイト全体の設定（「X が差し込むもの」と、x.com では「タイムラインの周り」）は、そのサイトの一覧の先頭にあります。カラムやビューの上です。

設定画面はサイトごとのタブに分かれています。X Pro のカラムと x.com のビューは、同じ画面に並ぶことがないためです。
